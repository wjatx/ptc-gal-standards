Broker to airlock: a mesh with no center

Agent A never talks to Agent B. A's broker talks to B's airlock, and B's broker talks to A's airlock. Each agent's broker is its only egress; each agent's airlock is its only ingress. Everything a mesh needs follows from repeating that one edge, and nothing in the middle has to exist.

1 · One edge, both directions

The sending agent asks its own broker to publish. The broker holds the peer credential the agent never sees, stamps the outbound provenance from the sending turn's actual state, signs the envelope, and sends. The receiver treats what arrives as an ordinary sender at its airlock: verify, screen, re-gate, and derive taint by its own trust map. Acting on the message still crosses the receiver's own broker.

2 · The same edge, repeated, is the mesh

Nothing about the edge is pairwise-special. Any agent that deploys an airlock and publishes an address can receive; any agent whose broker holds a peer credential can send. The mesh is the set of edges, and there is nothing in the center to stand up, govern, or compromise.

Why the edge composes

  • The symmetry is the design. Neither agent ever holds the other's address, credentials, or trust decisions. The mesh question dissolves into pairwise edges over any transport.
  • Authenticity is not content trust. The airlock verifying the sender grants nothing: sender-asserted labels are a floor, never a grant, and the receiver's own trust map stays the sole authorization authority. Authenticity never cleans a tainted chain.
  • Provenance is broker-stamped, never agent-authored. The outbound chain entry, and therefore the taint the receiver derives, comes from the sending broker's record of the turn. A relay re-packages and signs per hop; upstream hops ride as lineage.
  • Taint rides through. A peer's message enters at the AGENT level of the integrity lattice, so it can inform the receiver, while the standing tainted-external-write cut still governs anything the receiver does about it. Agent-to-agent needs no special rule.

A fully compromised agent can still only ask its broker to publish; it cannot forge the transport authenticity the peer will verify.

Status

The seam is contract-tier and shipped in the reference implementation: the channels contracts (PUBLISH, TRUST-MAPPING, SCREENING, SIGNING) carry conformance suites, and receiver-side signature verification is an envelope knob that ships OFF. This page describes a composition of those shipped parts with adopted transports. It is not a protocol proposal. The companion document is broker-airlock-mesh.md.
